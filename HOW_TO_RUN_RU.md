# Как запустить игры (простая инструкция для новичков)

🇬🇧 [Read in English](HOW_TO_RUN.md)

Каждая игра - это **один-единственный `.exe`-файл**. Ничего устанавливать **не нужно**: ни Godot, ни Blender, ни Python.
Скачали один файл, дважды кликнули - играете.

## Что нужно

- **Windows 10 или 11, 64-бит.**
- Видеокарта с поддержкой **Vulkan** и свежий драйвер (подойдёт практически любая NVIDIA или AMD за последние
  ~8 лет; современная графика Intel обычно тоже работает, но медленнее).
- Около **8 ГБ оперативной памяти** и **~500 МБ свободного места** на диске для каждой игры.
- Клавиатура и мышь.

## Шаг 1 - Скачайте один файл

Откройте страницу **Releases**: **https://github.com/Prokopiy8247/Fable5-2-Effort-Test-GTA/releases/tag/v1.0**

Прокрутите вниз до раздела **Assets** и нажмите на файл той игры, которую хотите попробовать. Нужен только **один** файл.

| Папка / уровень мышления | Игра | Какой файл скачать |
|---|---|---|
| `Low` | Port Fable | `Low_PortFable.exe` |
| `Medium` | Port Cinder | `Medium_PortCinder.exe` |
| `High` | Marlow Bay | `High_MarlowBay.exe` |
| `Extra` | Cinder Bay | `Extra_CinderBay.exe` |
| `Max` | Neon Tide: Vesper Bay | `Max_NeonTide.exe` |
| `Ultracode` | Halcyon Bay | `Ultracode_HalcyonBay.exe` |

Каждый файл весит примерно 105-150 МБ, так что загрузка может занять минуту.

## Шаг 2 - Запустите игру

1. Откройте папку **Загрузки**.
2. **Дважды кликните** по скачанному `.exe`-файлу.

### «Windows защитила ваш компьютер» / предупреждение браузера - это нормально

Игры - небольшие любительские сборки, они **не имеют цифровой подписи**, поэтому Windows и браузеры показывают
предупреждение.

- **Браузер** (Chrome / Edge) пишет, что файл «редко скачивают»: нажмите `...` рядом с загрузкой ->
  **Сохранить** -> **Всё равно сохранить**.
- **Windows SmartScreen** показывает синее окно «Windows защитила ваш компьютер»: нажмите **Подробнее** ->
  **Выполнить в любом случае**.
- Некоторые антивирусы при первом запуске проверяют файл несколько секунд. Это нормально.

Если вы не хотите запускать неподписанный файл, можно собрать и запустить игру самостоятельно из исходников - см.
раздел «Для продвинутых» внизу.

## Шаг 3 - Играйте

Первый запуск может занять от нескольких секунд до **~30 секунд**, пока строится город. Подождите, окно на мгновение может «зависнуть».

Основное управление (во всех шести играх оно почти одинаковое):

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение / управление машиной |
| Мышь | Осмотр, `ЛКМ` - стрелять, `ПКМ` - целиться |
| `Shift` | Бег |
| `Пробел` | Прыжок (ручной тормоз в машине) |
| `F` | Сесть в транспорт / выйти (угнать машину) |
| `E` | Взаимодействие (магазины, двери и т. д.) |
| `Tab` | Колесо оружия |
| `M` | Карта |
| `Esc` | Меню паузы |
| `F1` | Админ- / тестовое меню (создание транспорта, оружия и не только) |
| `F5` / `F9` | Быстрое сохранение / быстрая загрузка |

Между играми есть небольшие отличия (например, клавиша телефона). Точное управление описано в файле `DEVELOPMENT.md` внутри папки каждой игры (и в большинстве игр - в меню паузы). В `High` ещё работает `F11` - полноэкранный режим.

## Что-то пошло не так?

- **Ничего не происходит или окно сразу закрывается:** обновите драйвер видеокарты (сайт NVIDIA, AMD или Intel),
  перезагрузите компьютер и попробуйте снова.
- **Чёрный экран или вылет:** закройте тяжёлые программы (браузер с кучей вкладок, другие игры) и попробуйте ещё раз.
  Попробуйте другую игру из списка - они отличаются размером и сложностью.
- **Низкий FPS:** закройте лишние программы. Это большие игры с открытым миром, которые ИИ-агент сделал за одну сессию, поэтому производительность у разных игр отличается.
- **Антивирус удалил файл:** это ложное срабатывание на неподписанные программы. Верните файл из карантина и добавьте
  исключение либо воспользуйтесь вариантом «Для продвинутых» ниже.
- **Как удалить игру?** Просто удалите `.exe`. Сохранения (если они есть) лежат в `%APPDATA%\Godot\app_userdata\` -
  удалите там папку игры, если хотите стереть и их.

## Для продвинутых - запуск из исходников (необязательно)

1. Установите **Godot 4.7.2 stable** с https://godotengine.org/download/archive/ (обычная версия, не .NET).
2. Скачайте или клонируйте этот репозиторий.
3. Запустите Godot, нажмите **Import**, выберите файл `project.godot` в одной из папок (`Low`, `Medium`, `High`,
   `Extra`, `Max`, `Ultracode`) и нажмите **F5**, чтобы запустить игру.

Blender нужен только если вы хотите редактировать 3D-ассеты (файл `.blend` в каждой папке).
