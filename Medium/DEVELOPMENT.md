# Port Cinder — development notes

Original missionless GTA-style free-roam sandbox built for the Claude Fable 5.2 Godot + Blender MCP benchmark.

## Environment

| Item | Value |
|---|---|
| Engine | Godot **4.7.2 stable** (`W:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe`) |
| Renderer | Forward+ (`rendering_method="forward_plus"`), FXAA, SSAO, glow, filmic tonemap, 2048 directional shadow atlas |
| Language | GDScript only (no C#, no add-ons, no Asset Library content) |
| Blender | 5.2.2 LTS through the `blender-gta-medium` MCP server (tool namespace `mcp__blender-gta-medium__*`), endpoint `localhost:9878` |

| Backup | `.fable-5.2-gta-runs/run-20261109-214834/backups/GodotFable5.2GTAMedium_pre_session.blend` (git-ignored) |
| Safety defaults | V-Sync on, `Engine.max_fps = 60`, render scale 1.0, bounded particle pools, 10 pooled street lights |

Only the Blender instance on port 9878 was used. The MCP server also exposes asset-library / AI-generation tools
(Poly Haven, Sketchfab, Poly Pizza, generators); **none were called** — every mesh is authored by project scripts.

## Run / validate

```text
Open the folder in Godot 4.7 and press F5, or:
  Godot_v4.7.2-stable_win64.exe --path "<this folder>"

Automated, time-limited checks (each quits by itself, 60 fps cap, 1280x720):
  powershell -ExecutionPolicy Bypass -File tools\run_test.ps1 <scenario> [-Headless]
  scenarios: parse basic combat wanted vehicles extras menus misc city look perf world plane
Screenshots land in screenshots/.
```

`tools/run_test.ps1` checks `nvidia-smi` and backs off while the shared GPU is above 85 %, refuses to start a second
instance, and kills the process after a hard timeout. The game also has an in-process watchdog in test mode.

## Art direction

Clean, flat-shaded low-poly "sun-bleached coastal toy city": solid colour materials, chamfered silhouettes, real 3D
lettering on signs, emissive windows at night. Chosen because it can be applied consistently to ~150 authored assets and
stays readable at speed.

## Blender asset workflow (reproducible)

All assets are generated by Python executed **inside Blender through MCP** (`execute_blender_code`), inspected with the
MCP `look` tool, saved into the master `.blend`, and exported per asset as GLB:

```text
tools/blender/gta_lib.py              bmesh builder, materials, collections, UV projection, GLB export, manifest
tools/blender/vehicles.py             22 vehicles + 5 wheel styles + modular mod parts (spoilers, skirts, scoop, bull bar, exhaust)
tools/blender/characters_weapons.py   rigged human (13 bones, rigid skinning, M/F bodies, 14 accessories), 16 weapons with attachments, 7 animals
tools/blender/buildings.py            44 buildings / landmarks / track kit pieces
tools/blender/props.py                58 street props, interior props, pickups, nature
        ->  gta/generated/models/<category>/<asset>.glb   +   gta/generated/models/manifest.json
```

`manifest.json` carries bounds, collision boxes, ramps, wheel positions, seats, muzzles and door points so Godot builds
colliders and gameplay hooks without manual wiring. Collections in the `.blend`: `GTA_GODOT/{Characters,NPCs,Vehicles/{Cars,
Motorcycles,Boats,Helicopters,Airplanes,Wheels,Transit},Weapons,Buildings,StreetProps,Interiors,Nature,VFX_HelperMeshes,
CollisionHelpers}`. To rebuild everything, `exec()` the lib and call `build_all_vehicles()`, `build_human()`,
`build_weapons()`, `build_wildlife()`, `build_all_buildings()`, `build_props()`.

Conventions: Blender +Y is "forward" (Godot −Z); buildings face Blender −Y (Godot +Z); origins at ground centre, wheel
centre, or weapon grip. Materials are looked up by name in Godot (`Paint`, `Paint2`, `Glass`, `Window`, `LightHead`, …)
and overridden per instance (paint jobs, night windows, brake lights, clothing colours).

## Architecture

Everything is created in code from `gta/scenes/bootstrap/main.tscn` → `gta/code/core/main.gd`. Autoload `G`
(`core/game.gd`) holds shared references, input map, manifest and helpers.

| Path | Role |
|---|---|
| `core/defs.gd` | Data registries: weapons, attachments, vehicles, upgrades, paints, clothing, shop items |
| `core/skills.gd` | Use-based character stats |
| `world/world.gd` | Procedural 600×600 m island: ground, slabs, hill terrain, markings, water shader, building rows, props, signals, ped graph, runtime navmesh bake |
| `world/env.gd` | Day/night, weather, rain, lightning, pooled street lights, underwater fog |
| `world/extras.gd` | Pickups, loot, emergency services, monorail, taxi rides, activities |
| `player/player.gd`, `camera_rig.gd`, `humanoid.gd` | Controller state machine, camera, procedural skeletal animation |
| `vehicles/vehicle.gd` | One `RigidBody3D` class: raycast-suspension cars/bikes, buoyant boats, helicopters, airplanes, damage, upgrades |
| `traffic/traffic.gd` | Lane graph, signal-aware AI drivers, spawning, parked cars, carjacking, routing |
| `ai/npc.gd`, `population.gd`, `animal.gd` | Pedestrians, police, tactical, gang, clerks, crews; panic/witnesses; wildlife |
| `police/wanted.gd`, `police_heli.gd` | Crime intake, witnesses, 0–5 stars, pursuit/search, dispatch, roadblocks, air support, busting |
| `weapons/weapons.gd`, `projectile.gd`, `combat/fx.gd` | Inventory, hitscan/projectiles, melee, pooled VFX, explosions |
| `ui/hud.gd`, `minimap.gd`, `menus.gd` | HUD, radar/full map/GPS, all menus incl. the benchmark menu |
| `audio/audio.gd` | Fully synthesised SFX, loops, ambience and four radio stations (generated on a worker thread) |
| `save/save.gd` | JSON save in `user://port_cinder_save.json` |
| `debug/autotest.gd`, `tests.gd` | Scenario runner used for validation |

Physics layers: 1 world, 2 vehicles, 3 characters, 4 dynamic props, 5 triggers. Vehicles do not collide with characters;
run-overs use a shape query so a pedestrian never stops a car dead.

Performance techniques: pooled particles/decals/tracers/lights, distance-tiered NPC and traffic updates, animation LOD,
spawn/despawn rings around the player, frozen parked vehicles, MultiMesh vegetation, visibility ranges on small props,
importer-generated mesh LODs.

## Map — Port Cinder

Island, land x −300…300, z −300…214 (Godot units = metres). Roads: N–S at x = −240, −120, 0, 120, 240; E–W at
z = −200, −100, 0, 100, 200; the x = 0 / z = 0 avenues are four-lane; the outer ring is the fast loop.

Downtown (centre), Civic North (police, fire, hospital, parking garage), Larkspur residential + safehouse (west),
Signal Hill park with viewpoint (north-west), Ironside industrial + Torque Bay (east), Southshore, Saltline Beach and
Anchor Docks / marina (south), Westwood woodland (far west), Rustyard (far east, gang turf, shooting range), Cinder
Airfield (north: 560 m runway, hangar, helipads, tower). Elevated Skyline Metro along the z = 0 avenue.

## GPU / stability log

No stress signals were observed. All runs were frame-capped at 60, windowed 1280×720 or headless, one instance at a
time, each ≤ 115 s. Blender work used only Workbench/EEVEE viewport captures ≤ 1300 px; no Cycles, no bakes.
Measured at the 60 fps cap during a 4-star chase in a storm downtown: 60.0 fps average, worst frame 30 ms, ~1400 draw
calls, ~395 k primitives, ~91 MB video memory reported by the engine. No uncapped benchmark was run.

## Known limitations

- Validation was automated (scripted input + state assertions + screenshots). Nobody has hand-played it yet, so feel
  and balance (flight handling, police difficulty, prices) are first-pass values.
- Ragdolls are procedural tumble/limp poses, not physical bone simulation. Vehicle doors, trunks, convertible roofs and
  mesh deformation are not implemented.
- Shops are used from their storefront door markers; only the safehouse, the mod garage bay and the hangar are enterable.
- Traffic uses one AI lane per direction (no lane changes). Police pathing is a road-graph route plus local avoidance and
  can get stuck on cluttered yards; stuck units reverse or deploy on foot.
- The engine prints `Lambda capture … was freed` when a delayed callback outlives a despawned vehicle/NPC, and one
  navmesh-bake message at startup; both are harmless and guarded.
- Gamepad bindings exist but were not tested.
